PaperOffice AI provides API‑first, enterprise‑grade document AI, intelligent document processing and automation. Founded in Germany in 2002 and now operating as PAPEROFFICE ENTERPRISE OPERATIONS, S.L.U. in Pamplona, Spain, it offers a data‑center hosted in the EU, 40+ enterprise solutions, REST APIs, webhooks, MCP tools for Claude and ChatGPT, and integrations via Zapier, Make, n8n. The platform supports OCR in 120+ languages, knowledge‑base AI, AI agents for phone and chat, and a no‑seat‑license pricing model with monthly plans starting at €49.

**Areas:** Company · AI · DocumentProcessing · Enterprise · Automation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for PaperOffice AI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
